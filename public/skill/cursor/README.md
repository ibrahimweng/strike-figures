# Strike design for Cursor
- Unzip `strike-design-cursor.zip` in your project's root. It adds `.cursor/rules/` and `strike-design/` (tokens, logo files, fonts, the checker).
- `strike-design.mdc` always applies; the other rules load when the agent needs them. `rules/` here shows the same files.
- Check work with `node strike-design/scripts/check.mjs <files>`.
- Generated by `npm run build` in strike-design-skill; change `source/` there, not these files.
