# Strike design for any other AI tool
- Attach or paste `STRIKE-DESIGN.md` at the start of a chat and say: "Follow these rules for Strike work."
- `strike-design-kit.zip` adds the tokens, logo files and fonts, for tools that take files.
- Check what it makes with `node scripts/check.mjs <file>` in the repository.
- Generated by `npm run build` in strike-design-skill; change `source/` there, not these files.
