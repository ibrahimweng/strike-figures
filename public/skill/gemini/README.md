# Strike design for Gemini
- In Gemini, open Gems, choose New Gem and name it Strike design.
- Paste `gem-instructions.md` into Instructions.
- Add files from `knowledge/`: `STRIKE-DESIGN.md` first, then the tokens and the logo files you use most.
- Generated by `npm run build` in strike-design-skill; change `source/` there, not these files.
