# Strike design for GitHub Copilot
- Unzip `strike-design-copilot.zip` in your repository's root. It adds `.github/copilot-instructions.md` and `strike-design/`.
- Already have a copilot-instructions.md? Add the text of `copilot-instructions.md` to the end of yours.
- Copilot Chat and the coding agent read it for that repository.
- Generated by `npm run build` in strike-design-skill; change `source/` there, not these files.
