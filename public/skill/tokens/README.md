# Strike design tokens
- `tokens.css`: CSS variables, dark on `:root` and light under `[data-theme="light"]`, plus type classes (`.strike-h1` and the rest).
- `tailwind.preset.cjs`: Tailwind v3, `presets: [require('./tailwind.preset.cjs')]`; load tokens.css too for light mode.
- `theme.css`: Tailwind v4, `@import "tailwindcss"; @import "./theme.css";`. `tokens.json`: the source values (W3C Design Tokens).
- Generated by `npm run build` in strike-design-skill; change `source/` there, not these files.
