# Strike design for Figma
- Variables: import `tokens.json` (steps in `SETUP.md`).
- Figma Make: use `guidelines.md` as the file's Guidelines.md (steps in `SETUP.md`).
- Logo files: drag the SVGs in `logos/` onto the canvas.
- Generated by `npm run build` in strike-design-skill; change `source/` there, not these files.
